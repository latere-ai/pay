# Documentation

| Guide | Read it when |
|---|---|
| [Getting started](getting-started.md) | You want to sell credit and spend it, end to end |
| [The money model](money-model.md) | You want to know why a balance is a fold and what a hold is for |
| [Webhooks](webhooks.md) | You are mounting the endpoint and want the status codes right |
| [Writing an adapter](adapters.md) | Your processor is not one this library ships |
| [Running Stripe](stripe-operations.md) | You are configuring the account, not writing code |

API reference is on [pkg.go.dev](https://pkg.go.dev/latere.ai/x/pay).

Changing the library rather than using it? [`CONTRIBUTING.md`](../CONTRIBUTING.md)
covers building and testing a change, and [`../specs/`](../specs/README.md) is
the design record, including the approaches that were tried and rejected.
